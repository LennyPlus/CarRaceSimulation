# CarRaceSimulation
A JavaFx application that simulates a car race with 4 or 5 cars using the Model-View-Controller architecture for the Program Development in a Graphical Environment course at Vanier. 

The color and speed of each car is randomly generated at runtime. Each car can have a speed value between 20 to 50. To generate a new set of cars, close the app and reopen it.

By Anas issa

## Usage

1. Open the project in NetBeans
2. Download the required dependencies using Maven
3. Run the main application file: `CarRaceFXML.java` (located in the `com.mycompany.carracesimulation` package)
4. Press the start button to start the race

## Controls
- Start Button: Starts the race
- Pause Button: Pauses the race
- Reset Button: Resets the cars to their original positions
- Speed Slider: Adjusts the simulation speed of the race
